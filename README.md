# Bihar Election Tracker 2025 

**Live interactive election results tracker for Bihar Assembly Elections 2025**

 **Live Website**: [live-results-tracker.onrender.com](https://live-results-tracker.onrender.com)

---

##  Features

-  Automated scraping every 5 minutes via GitHub Actions
-  Interactive Bokeh map with clickable constituencies
-  Advanced filtering (Parliament Seat, District, Party, Lead Margin)
-  Mobile responsive design
-  Real-time updates with no manual intervention

---

##  Tech Stack

- **Backend**: Flask 3.0.0
- **Scraping**: Selenium 4.15.2 (8 concurrent workers)
- **Mapping**: Bokeh 3.3.0 + GeoPandas
- **Automation**: GitHub Actions (every 5 minutes)
- **Deployment**: Render (auto-deploy)

---

##  Performance

- **Scraping**: ~5-7 minutes for 243 seats
- **Updates**: Every 5 minutes
- **Page Load**: <2 seconds
- **Traffic**: ~147 requests on election day
